## 📑 Índice de proyectos

### 🔹 UT1: **introduccionJava**
- **Descripción:** Introducción a los fundamentos de Java.  
- **Ejemplos incluidos:**  
  - Hello World 
  - Calculadora
- **Conceptos clave:** sintaxis básica, herencia, colecciones, excepciones, entrada y salida.


## 🚀 Cómo ejecutar los proyectos
1. Clona este repositorio:
   ```bash
   git clone https://github.com/miguel-goyena-cv/2DAM_PSP_26-27.git
   ```
2. Importa el proyecto en tu IDE favorito (IntelliJ, Eclipse, VS Code con extensión Java).  
3. Compila y ejecuta desde la clase `Main`.
